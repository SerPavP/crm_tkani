# Changelog - CRM Система управления тканями

## Версия 1.25 (текущая)

### ✨ Новые функции

#### 1. Модальное окно для создания сделок
- **Глобальное модальное окно**: Кнопка "Создать заказ" в навигации теперь открывает модальное окно на всех страницах
- **Быстрое создание**: Создание сделки без перехода на отдельную страницу
- **Context processor**: Список клиентов доступен глобально для модального окна

#### 2. Улучшения PDF для печати на склад
- **Информация о клиенте**: В PDF для печати на склад добавлена информация о клиенте перед таблицей
- **Упрощенный формат**: Убран номер телефона, оставлено только имя клиента

#### 3. Кликабельные элементы в топ-20
- **Кликабельные клиенты**: В топ-20 клиентов добавлены ссылки на страницы клиентов
- **Кликабельные ткани**: В топ-20 тканей добавлены ссылки на страницы тканей
- **AJAX поддержка**: Ссылки работают как для статических, так и для динамически загружаемых данных

#### 4. Улучшения интерфейса финансов
- **Подробные даты**: В топ-20 клиентов добавлено отображение подробных дат для режима "месяцы"
- **Формат дат**: Отображение в формате "с 1 сентября 2025 г. по 31 октября 2025 г."

#### 5. Информация о разработчике
- **Footer обновлен**: Добавлена информация о создателе (SolveMint) и версии приложения
- **Версия 1.25**: Отображение текущей версии в подвале сайта

## Версия 1.2.5

### 🔄 Миграция на PostgreSQL

#### 1. Переход с SQLite на PostgreSQL
- **Поддержка PostgreSQL**: Добавлена полная поддержка PostgreSQL для повышения производительности и надежности
- **Скрипт миграции**: Создан автоматизированный скрипт для переноса данных из SQLite в PostgreSQL
- **Конфигурация через переменные окружения**: Настройки базы данных теперь хранятся в файле `.env`

#### 2. Улучшения безопасности
- **Защита конфиденциальных данных**: Пароли и ключи вынесены в переменные окружения
- **Обновленный шаблон env_template.txt**: Добавлены все необходимые переменные для PostgreSQL

#### 3. Документация по миграции
- **Подробное руководство**: Создан файл postgres_migration_guide.md с инструкциями по миграции
- **Обновление README.md**: Добавлена информация о работе с PostgreSQL
- **Инструкции по устранению неполадок**: Добавлены решения типичных проблем с PostgreSQL
