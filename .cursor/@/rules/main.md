## О проекте
CRM для бизнеса по продаже тканей. Модули: главная панель (`core`), сделки (`deals`), ткани/цвета (`fabrics`), клиенты (`clients`), склад рулонов (`warehouse`), финансы и отчёты (`finances`).

## Ключевые принципы разработки
- **Простота и читабельность**: Чёткие слои — представление (шаблоны), логика (сервисы), данные (модели).
- **Безопасность**: секреты из окружения, CSRF, минимизация раскрытия данных, валидация на входе.
- **Производительность**: избегать N+1, индексы, кэш, продуманная агрегация для отчётов.
- **Тесты**: покрывать критические сценарии (создание сделки, списание склада, расчёты в финансах).

## Что где искать
- `templates/` — страницы и компоненты.  
- `static/` — CSS/JS/изображения (сборка в `staticfiles/`).  
- `*/models.py` — данные и бизнес-ограничения.  
- `core/` — общие сервисы/утилиты.  

## Вклад в проект
- Перед изменениями — обновите документацию и проверьте миграции.  
- Коммиты атомарные с понятными сообщениями.  
- Не коммитьте артефакты сборки и локальные данные.

## Нельзя
- Хранить/просматривать `.env` в репозитории.  
- Вставлять секреты/ключи в код.  
- Давать `|safe` без крайней необходимости.

## Запуск (dev)
- Python 3.11+, `pip install -r requirements.txt`, `python manage.py migrate`, `python manage.py runserver`, открыть `http://127.0.0.1:8000/`.

## Роли
- Администратор, Бухгалтер, Кладовщик — права разграничены на уровне UI и API.
